## **🎮 Word Hunter**

Word Hunter is a simple Python-based word guessing game made using Pygame.

The player has to guess the hidden word by selecting letters. A hint is provided to help the player guess the correct word.

## 🎯 Features
🎮 Simple and interactive Pygame interface
💡 Hint for every word
🔤 Clickable alphabet buttons
❤️ 6 lives for each game
⭐ Score system
🔄 Play Again option
❌ Exit button
🎲 Random word selection

⚙️ Installation

Make sure Python is installed on your computer.

Install Pygame using:

pip install pygame


Or install the required packages using:

pip install -r requirements.txt

▶️ How to Run

Clone the repository:

git clone https://github.com/shivampatale/Word-Hunter.git


Go into the project folder:

cd Word-Hunter


Run the game:

python main.py

🎮 How to Play
Start the game.
Read the hint displayed on the screen.
Click a letter from the alphabet.
If the letter is correct, it appears in the hidden word.
A correct guess gives 10 points.
A wrong guess reduces one life.
Guess the complete word before losing all 6 lives.
After the game ends, choose PLAY AGAIN or EXIT.
